## 2026-08-08 实测结论（重要修正）

**此前"所有功能不可用"的判断是测试方法错误**：probe 脚本未 pump 目标窗口 → crisp_overlay 的
dual-hide capture（ShowWindow(target, SW_HIDE)）跨进程阻塞 → overlay 主循环卡死 → 渲染不执行。
正确验证（pump target + 锐度指标）：

| 组合 | 锐度 | 结论 |
|------|------|------|
| baseline（无 overlay） | 24.4 | — |
| wash39 tint0 r5 | 8.1 | 模糊生效 ✓ |
| wash39 tint0 r30 | 7.8 | 半径增大略增 ✓ |
| wash39 tint0 r60 | 7.7 | ✓ |
| wash39 tint12 r10 | 8.0 | ✓ |
| wash39 tint30 r10 | 6.4 | tint 压暗 ✓ |
| wash255 tint0 r60 | 1.1 | 全强度大半径强模糊 ✓ |

**Crisp 渲染管线（wash/tint/radius）实测全部正常**。遗留：HIDE 事件竞态防御
（g_inCapture/g_captureDoneAt，理论竞态，保留无害）；焦点差异化/圆/崩溃守卫仍需真实桌面验证。
